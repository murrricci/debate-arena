## Проверка ограничения "не больше 3 боев"

UI/domain-логика блокирует 4-й разминочный бой: `canPlayWarmup(participant)` возвращает false при `stats.battles >= 3`, а `Arena.jsx` не запускает ручной бой для таких агентов.

Но авторизованный backend endpoint `POST /api/results` принял 4-й бой для пары `9928`/`9929` после трех боев:

- первые три sacrificial боя: battle `19`, `20`, `21`
- 4-я попытка: HTTP `200`, battle `22`
- после проверки очки `9928`/`9929` были сброшены через `POST /api/results/reset` только для этих двух тестовых агентов

Итог: найден дефект backend enforcement. Детали и план исправления в `test_report_fixplan.md`.
